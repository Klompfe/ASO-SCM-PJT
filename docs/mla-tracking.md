# MLA-### 작업 추적 (자재명세 에이전트 관련, 외부 세션 유입분)

PR-###는 aso-scm 자체 기능 개발/버그수정 번호 체계이고, MLA-###는 별도
Claude 대화에서 설계된 자재명세(Material List) 자동화 규칙·에이전트 구조를
이 프로젝트에 반영하는 작업만 추적하는 번호 체계다. 두 번호는 서로 독립적으로
1부터 증가하며, 절대 같은 번호를 공유하거나 서로의 시퀀스를 침범하지 않는다.

MLA 작업이 실제 코드 변경을 동반해 커밋/머지된 경우, 해당 커밋 메시지나 PR
설명에 '(MLA-###)'를 함께 표기해 추적 가능하게 한다. 이 경우에도 PR-### 번호는
별도로 정상 채번한다 — MLA 번호가 PR 번호를 대체하지 않는다.

현재 PR 번호는 PR-160까지 진행됨(2026-10-01 기준) — 앞으로 PR 채번 시 이 문서도 같이 참고.

**실제 데이터 입력 경로**: 자재명세의 근거가 되는 작업지시서는 aso-scm에서 **오더관리 메뉴 → 오더 목록 → "수주 등록"**으로 업로드된다(작업지시서가 사실상 수주 역할을 함). 생산 실행 지시인 `작업지시`/`WorkOrder`(work-orders 메뉴)와는 이름만 비슷한 별개 개념이다. 자세한 내용은 `docs/material-list-rules.md`의 "0. aso-scm 시스템에서의 실제 데이터 입력 경로"와 `docs/API-FRONTEND-MAPPING.md`의 "sales-orders" 절 참고.
