# 작업지시서 → MATERIAL LIST 작성 규칙

**(주)미도컴퍼니 — 미센스 / 반에크 자재명세 작성 표준**

---

## 1. 목적

작업지시서(작지)를 근거로 신규 스타일의 MATERIAL LIST(자재명세)를 작성하거나, 기존 스타일에 추가·변경 내용을 반영할 때 지켜야 할 공통 규칙을 정리한다. 판독 오류를 줄이고, 원본 서식(병합·테두리·글자크기)을 손상시키지 않으며, 미확정 정보와 확정 정보를 시각적으로 명확히 구분하는 것을 목표로 한다.

**본 규칙은 미센스·반에크 두 파일의 모든 시트(모든 스타일)에 예외 없이 동일하게 적용한다.**

**적용 범위**: 이미 작성된 기존 시트뿐 아니라, **앞으로 신규로 작성되는 모든 시트에도 예외 없이 이 규칙을 적용한다.** 새 스타일의 작업지시서를 받아 시트를 추가할 때마다 이 문서의 규칙을 기준으로 작성하며, 담당자가 별도로 지시하지 않아도 항상 기본으로 따른다.

---

## 2. 기본 작업 절차

| No | 항목 | 규칙 |
|---|---|---|
| 1 | 스타일 배정 | 스타일번호가 MB로 시작 → 미센스 파일 / LB·VB로 시작 → 반에크 파일. 시트명은 스타일번호에서 하이픈(-)을 제거해 기입 (예: LB73-JKM-1912 → 원본 표기 재확인 후 정확히, 예: LB73JKM191Z). |
| 2 | 서식 원본 유지 | 반드시 품목(JK/SL/SK/BL/OP 등)과 컬러 수가 같은 기존 스타일 시트를 그대로 복제해서 사용한다. 새 서식을 만들지 않는다. |
| 3 | 병합 셀 절대 해제 금지 | 값을 입력할 때 병합된 셀은 대표(좌상단) 셀에만 쓴다. 병합을 해제하고 다시 합치는 방식은 테두리·글자크기가 깨지므로 금지한다. |
| 4 | 행이 모자랄 때 | 새 항목을 넣을 칸이 없으면 반드시 행을 삽입해서 처리한다. 삽입 시 기존 병합 범위를 먼저 해제·기록 → 행 삽입 → 병합 범위를 원래 위치대로(삽입 지점 아래는 행 수만큼 이동) 복원한다. (엑셀 자체의 '행 삽입' 기능은 병합 셀을 잘못 늘리는 경우가 있어 반드시 결과를 검증한다.) |
| 5 | 글자 크기·서식 일치 | 새로 입력하는 값은 같은 열의 위·옆 칸과 같은 글자 크기·서식을 사용한다 (예: 규격(SPEC)란이 16pt이면 새 값도 16pt). |

## 3. 색상 표시 규칙

자재 항목의 확정/미확정 상태는 다음 3가지 배경색으로만 구분한다. 그 외 색상(노란색 등 구버전 표시)은 사용하지 않는다.

| 배경색 | 의미 | 적용 예 |
|---|---|---|
| **빨간색** (FF0000, 원본과 동일) | 확정 미사용 자재 — 작업지시서에 해당 항목이 전혀 없거나, 배색·옵션 장식처럼 이 스타일에는 적용되지 않는 것이 명백한 경우 | 배색(COMBINATION) 원단, 이 스타일에 없는 지퍼/단추 종류 등 |
| **연한 파란색** | 미확인 — 안감/심지/테이프/단추/봉사/패드/지퍼처럼 핵심 부자재라 사용 가능성은 높지만, 작업지시서 손글씨를 판독하지 못해 수치(요척 등)를 못 채운 경우 | 요척 숫자가 뭉개져 안 보이는 심지, 규격이 겹쳐 쓰여 분리 불가능한 항목 등 |
| **배경색 없음(무색)** | 실제 값이 확인되어 정상 입력 완료된 항목, 또는 라벨/택/폴리백처럼 관례상 항상 쓰는 필수 소모품 | 겉감 요척, 라벨/가격택/사이즈스티커/택고리/이미지택/폴리백 등 |

> **주의**: '미사용(빨간색)' 여부는 반드시 **항목명이 적힌 첫 칸(A열)이 빨간색인 경우에만** 판정한다. 도너 시트의 다른 데이터 칸에 남아있는 빨간색은 무시한다 (실제로 사용 중인 자재를 오판할 수 있음).

## 4. 항목별 입력 규칙

### 4.1 헤더 (STYLE NO / QTY / FACTORY / BUYER)

- FACTORY 칸은 도너 시트의 원래 기본값(예: 베트남)을 그대로 둔다. 작업지시서의 '생산처'(재원/태일/삼정 등)는 실제 해외 생산공장이 아니라 국내 임가공·샘플 협력업체명인 경우가 많으므로 FACTORY 칸에 덮어쓰지 않는다.
- BUYER는 '미도컴퍼니'로 고정, STYLE NO/QTY/납기는 작업지시서 값을 그대로 입력한다.

### 4.2 컬러 / 사이즈

- 작업지시서에 표기된 컬러명과 사이즈별(0/1/2 또는 55/66/77 등) 수량을 그대로 입력한다. 사이즈 라벨 체계가 도너 시트와 다르면 헤더(4행)도 함께 수정한다.
- 사용칼라(COLOR USED, F열)는 작업지시서 접수 시점에는 알 수 없으므로 항상 공란으로 둔다.

### 4.3 겉감(OUT-SHELL)

- 규격(폭)과 요척은 작업지시서 상 가장 신뢰도 높은 숫자이므로 반드시 채운다. 손글씨가 애매하면 **요척 = 출고량 ÷ 총수량**으로 역산해 교차검증한다.
- 혼용률(AA열)은 작업지시서 하단 성분표기를 반영한다. **컬러마다 혼용률이 다를 수 있으므로**(화살표 표기 확인) 컬러별로 정확히 구분해서 입력한다.
- 안감은 별도 표기가 없으면 **'P 100%'를 기본값**으로 입력한다.

### 4.4 부자재 (안감/심지/테이프/단추/지퍼/장식 등)

- 자재코드(M-250, M-2015 등)가 명시된 경우 코드 단위로 정확히 구분하여 입력한다. 서로 다른 자재를 `44"/58"`처럼 하나의 칸에 뭉쳐 넣지 않는다 — 분리가 안 되면 값은 비우고 연한 파란색으로 표시한다.
- 테이프·단추처럼 같은 대분류 안에 여러 세부 항목이 있는 경우(예: 다데테이프/암홀테이프, 겉단추/밑단추/금속단추) 각각을 별도 항목으로 정확히 매칭한다.
- 작업지시서에 전혀 언급이 없는 항목은 빨간색(확정 미사용) 처리한다. 다만 **라벨류·가격택·사이즈스티커·택고리·이미지택·폴리백 등 관례상 항상 들어가는 필수 소모품**은 언급이 없어도 빨간색 처리하지 않고 기본값 1로 채운다.

### 4.5 공급처 / 단가 / 발주·선적 일자 / 입고수량

- 작업지시서를 접수하는 시점에는 아직 발주·선적이 이루어지지 않았으므로, **공급처(MILL)·단가·발주일자·DATE·입고수량(RCVD) 칸은 모두 공란**으로 둔다. 실제로 자재가 입고되기 전까지는 값을 채우지 않는다.

### 4.6 REMARK'S (비고, AB열)

- 이 칸은 실제 선적이 이루어진 뒤 '언제, 무엇으로 선적했는지'(예: 3/20 SHIP SEND)를 기재하는 용도이다. 작업지시서 작성 시점에는 아무것도 적지 않고 공란으로 둔다.

## 5. 판독이 어려운 경우 처리 원칙

작업지시서 손글씨(특히 소수점 요척, 혼용률 비율)는 오독 가능성이 높다. 다음 순서로 신뢰도를 높인다.

1. **요척 = 출고량 ÷ 총수량**으로 역산해 교차검증한다.
2. 그래도 확신이 없으면 값을 채우지 않고 **연한 파란색**으로 표시해 담당자가 직접 확인하도록 남긴다.
3. 절대로 불확실한 숫자를 임의로 합치거나 추정해서 채우지 않는다.

## 6. 자주 발생했던 오류와 재발 방지 대책

| 오류 유형 | 원인 | 재발 방지 대책 |
|---|---|---|
| 병합 셀이 풀리고 테두리·글자크기가 깨짐 | 값 입력 시 병합을 해제하고 다시 쓰는 방식 사용 | 병합된 셀은 대표(좌상단) 셀에만 값을 쓰고 병합 해제 금지 |
| 행 삽입 후 옆 칸 병합이 여러 행에 걸쳐 잘못 늘어남 | Excel의 자동 행삽입 기능이 병합 범위를 잘못 확장 | 행 삽입 전 병합 범위를 모두 해제·기록 → 삽입 → 원래 구조대로 재병합 |
| 서로 다른 자재의 규격/요척이 한 칸에 뭉쳐 입력됨 (예: 44"/58") | 자재코드별로 구분하지 않고 하나의 항목으로 처리 | 자재코드(M-250 등) 단위로 항목을 분리해서 매칭, 불확실하면 공란+연한 파란색 |
| 실제 사용 중인 자재가 '미사용(빨간색)'으로 잘못 표시됨 | 도너 시트의 일부 데이터 칸에 남아있던 이전 스타일의 빨간색 표시를 '미사용 표식'으로 잘못 인식 | 항목명이 적힌 첫 칸(A열)이 빨간색인 경우에만 '미사용'으로 판정 |
| 필수 소모품(라벨/택/폴리백)이 빨간색으로 잘못 표시됨 | 작업지시서에 특별한 언급이 없다는 이유만으로 미사용 처리 | 관례상 필수인 항목 목록을 별도로 두고 언급 여부와 무관하게 기본값 1 입력 |
| 혼용률이 겉감/안감 구분으로만 처리되어 컬러별 차이를 놓침 | 화살표로 표시된 컬러별 혼용률 차이를 확인하지 않음 | 컬러마다 혼용률을 개별 확인, 안감은 표기 없으면 P 100% 기본값 |

## 개정 v2 (MB72JKM101A 검토 결과 반영)

기존 조항과 충돌하면 **이 개정 내용이 우선**한다.

### v2-1. 미사용 자재는 표시하지 않고 삭제한다
- 작업지시서에 없는 자재(예: 싸개패드, 배색, 사용하지 않는 심지·배색사)는 **빨간색 표시 없이 블록(행) 자체를 삭제**한다. (3장의 빨간색 규칙은 폐지)
- 삭제 시 병합 범위·행 높이·같은 행 수식(`=K*B`, `=R-M`)을 함께 재정렬한다.
- 목표: 작업지시서와 99% 일치. 나머지 1%는 사용자가 보완한다.
- 배경색은 **연한 파랑(미확인)** 과 **무색(확정)** 두 가지만 쓴다.

### v2-2. ITEMS(A열) 표기 규칙: 3단 구성
```
한글명(스펙; 예: M-475)
영문명 (선적서류용)
쓰임새 (작지 비고란) 또는 특기사항
```
예: `심지(M-475)` / `INTERLINING` / `몸판`. 기존 시트의 라벨이 이와 달라도 이 규칙을 따른다. 비고란이 비어 있으면 3단째는 비운다.

### v2-4. 이미지 해상도
- 작지 PDF에 들어 있는 스캔은 **150ppi 흑백**이다. 500dpi로 렌더링해도 원본 화소를 확대할 뿐 손글씨가 선명해지지 않는다.
- 판독 절차: 표 영역별로 크롭 → 확대(Lanczos) → 대비 강화 → 봉제 용어와 대조 → 요척은 `출고량÷총수량`으로 검산.

## 개정 v3 (생산처 필터 · LOT 표기 · 목록 갱신 시점)

### v3-1. 생산처(태일 외) 필터링
- 작업지시서의 생산처가 **"재원" 또는 "삼정"으로 명시된 건은 처리 대상에서 제외**한다. 이 프로젝트가 다루는 범위는 원칙적으로 "태일" 생산분이다.
- 생산처가 **"미기재" 또는 불명확한 경우는 잠정적으로 "태일" 배정으로 간주해 포함**한다. 나중에 재원/삼정으로 확인되면 그때 제외한다.
- 이미 시트로 만들어진 재원/삼정 건은 삭제하지 않고 그대로 둔다(작업 이력 보존). 다만 **스타일 개요 목록에서는 제외**한다.
- 적용 시점: ①(입력수집) 또는 ④(스타일-시트 매핑) 단계에서 헤더의 생산처를 읽은 직후 판정한다.

### v3-2. LOT 표기 해석
- 작업지시서에 "LOT①/LOT②"처럼 원단 출고량이 여러 줄로 나뉘어 있는 경우, 이것은 **별도의 주문 행이 아니라 같은 사이즈에 대한 추가 원단 출고(재단 로트)일 수 있다.**
- 사이즈별 수량표에서 특정 사이즈 칸에만 추가로 숫자가 적혀 있고 나머지 칸이 비어 있으면, **그 숫자는 해당 사이즈 칸에 합산**하는 것을 1순위 가설로 삼는다(예: 66사이즈에 LOT① 68 + LOT② 218 → 66사이즈 합계 286).
- 사이즈 칸 합계가 폼에 인쇄된 색상별 합계·총합계와 안 맞으면, **원단 출고량(LOT별 야드)의 비율**을 교차검증 근거로 쓴다 — 손글씨 사이즈 숫자보다 출고량 숫자가 더 크고 뚜렷하게 적혀 있어 신뢰도가 높은 경우가 많다.
- 그래도 안 맞으면 폼의 인쇄된 총계보다 **사용자가 원본을 보고 확정한 값을 최종 우선**한다.

### v3-3. 스타일 개요 목록 갱신 시점
- 새 작업지시서를 처리할 때마다(신규든 기존 확인이든) **그 스타일을 스타일 개요 목록(엑셀)에도 같은 턴에 추가/갱신**한다. 자재명세 시트만 만들고 개요 목록 갱신을 누락하지 않는다.
- 개요 목록에 추가할 때도 v3-1의 생산처 필터를 동일하게 적용한다(재원/삼정 제외, 미기재는 잠정 포함).
- 개요 목록에서 스타일번호 표기가 실제 시트명과 다를 수 있음에 유의한다(하이픈 유무, OP/PM 등 품목 코드 오독 — 예: MB72PM181A로 기재됐던 것이 실제로는 MB72OPM181A).

### v3-4. 작성일자는 "공란 처리 대상"이 아니다
- **작성일자**(문서 상단 "작업지시서" 제목 바로 아래의 "OO년 OO월 OO일")는 작지 자체에 이미
  인쇄되어 있는 확정 사실이다. 발주·선적처럼 "아직 정해지지 않아서 비워두는 값"이 아니므로,
  4.5의 공란 규칙(공급처·단가·발주·선적 일자)과 **절대 같이 묶어서 지우지 않는다.**
- 작성일자는 작지에서 읽은 값을 **Z8에 그대로 채운다.**
- UP DATE(Z9)·1st SHIP DATE(Z10)는 계속 공란으로 둔다 — 이 둘은 실제로 선적 전이라 모르는 값이
  맞다. 구분 기준: **"이미 지나간 사실(작성일자)"은 채우고, "아직 안 일어난 일(발주 이후 진행상황)"
  만 비운다.**
- 납기(Z11, "계획DELI"의 "납기"란)는 이미 규칙에 있었으나 실제 적용 시 누락되는 사례가 있었다.
  작지에 인쇄된 값을 빠짐없이 옮겨 적었는지 A9 검증 단계에서 반드시 재확인한다.
