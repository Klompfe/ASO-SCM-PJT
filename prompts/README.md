# prompts/ — 지시서 큐 (PR-155)

클라우드 세션이 작성하는 `PR-*-prompt.md` 지시서를 모아두는 곳입니다. 지금까지는 제시님 컴퓨터의 별도 폴더에만 있었지만, 앞으로는 여기에 모아 저장소에서 버전 관리합니다.

## 파일명 규칙

`PR-<번호>-prompt.md` (예: `PR-156-prompt.md`). `scripts/run-prompt-queue.sh`가 번호 순서로 처리합니다.

## 큐 정책(queue-policy)

지시서 파일 맨 위(첫 줄)에 다음 중 하나를 표시할 수 있습니다.

```
<!-- queue-policy: continue -->
```
또는
```
<!-- queue-policy: pause-after -->
```

- **표시가 없으면 기본값은 `pause-after`**(안전한 쪽)입니다.
- 스키마 변경/권한/보안/과금처럼 되돌리기 번거로운 PR은 반드시 `pause-after`를 쓰거나 표시를 생략해야 합니다(예: PR-151, PR-153처럼 병합 전 검토가 필요했던 것들).
- `pause-after`로 처리된 항목은 **브랜치에 커밋까지만 하고 main 병합·배포는 하지 않습니다.** 사람이 `prompt-reports/`의 보고서를 보고 확인한 뒤 별도로 병합을 진행합니다.
- `continue`로 처리된 항목도 큐 스크립트 자체가 병합까지 자동으로 하지는 않습니다 — 이 저장소의 기존 관행(PR 브랜치 → 사람의 확인 → 병합)은 자동화 인프라가 우회하지 않습니다. `continue`는 단지 "이 프롬프트 처리가 끝나면 큐를 멈추지 않고 다음 프롬프트로 넘어간다"는 뜻입니다.

## 처리 결과

각 지시서 처리 결과는 `prompt-reports/PR-<번호>-report.md`에 저장됩니다. 이미 보고서 파일이 있으면 해당 지시서는 건너뜁니다(재실행해도 안전).
